# CURRENT_TASK — M5: избранные репозитории

Детальное ТЗ текущего шага. Основа — `AGENTS.md`.

## Цель

Добавить избранные репозитории рядом с уже существующими избранными авторами:
звёзды в списке и панели деталей, фильтр «только избранное», управление в
настройках. Хранение — `config.json`, версия 3.

## A. Конфиг — `src/02-Config.ps1`

1. `Get-GhlDefaultConfig`: `Version = 3`, `FavoriteRepos = @()`.
2. `Get-GhlFavoriteRepos`: `owner/repo`, обрезка пробелов и слэшей, проверка
   `login/name` (логин — буквы/цифры/дефис; имя также `.` и `_`), дедуп без учёта
   регистра, лимит 30; одиночный элемент после JSON — строка, поэтому всегда
   `@(...)`.
3. `Add-GhlFavoriteRepo` (новый — в начало), `Remove-GhlFavoriteRepo`,
   `Test-GhlFavoriteRepo` — по образцу функций для авторов.
4. Нормализация при загрузке: `FavoriteRepos` всегда приводится к валидному
   массиву; миграция версий < 3 → 3 с записью в лог.

## B. Модель и список — `src/08-Main.ps1`, `ui/MainWindow.xaml`

1. `GhlRepoRow.IsFavorite` — свойство с `INotifyPropertyChanged`.
2. В ячейке Repository — звёздочка (`Segoe MDL2 Assets`), видимая по
   `DataTrigger IsFavorite=True`.
3. В шапке списка — чип `tglFavOnly` («Favourites»), фильтрует через
   `ICollectionView.Filter` (`$state.FavoritesOnly`), счётчик и пустое состояние
   учитывают его («No favourite repositories»).
4. В панели деталей — кнопка-звезда `btnFavRepo` (заполненная/контурная,
   подсказка меняется), скрыта без выбранной строки.
5. `Set-GhlRepoRows` выставляет `IsFavorite` при загрузке списка.

## C. Действия и синхронизация

1. `Set-GhlFavoriteRepo` добавляет/удаляет, сразу сохраняет конфиг (клик по
   звезде не должен теряться при сбое) и вызывает `Update-GhlFavoriteReposUi`.
2. `Update-GhlFavoriteReposUi` обновляет звёзды всех строк, список в настройках,
   подсказку и фильтр, если он включён.
3. Настройки, вкладка General: секция `FAVOURITE REPOSITORIES` — чипы
   `lstFavRepos`, подсказка, `btnRemoveFavRepo` (активна при выборе).
4. `Save-GhlUiConfig` нормализует `FavoriteRepos` перед записью.

## D. Тесты

1. Unit: нормализация (`/octocat/Hello-World/` → `octocat/Hello-World`), дедуп
   без учёта регистра и порядок «новый сверху», мусор отбрасывается, лимит 30,
   JSON-ловушка одного элемента, миграция конфига до версии 3.
2. Оконный сценарий `demo-tool`: клик по `btnFavRepo` ставит звезду и пишет
   `owner/repo` в конфиг; фильтр оставляет 1 строку; в настройках General виден
   один чип, `Remove selected` удаляет избранное, звезда и фильтр сбрасываются;
   выключение фильтра возвращает список.
3. `Run-Tests.ps1 -Offline` — 29; mock-набор — 17; UiRepeat — 3.

## F. Не входит

## G. Риски

- Частая запись конфига при каждом клике: файл маленький, запись атомарная;
  авторы сохраняются как раньше, по Done/закрытию.
- Избранный репозиторий может отсутствовать у загруженного пользователя: он
  остаётся в настройках, но в списке не появляется.
- Автосортировка WPF может перекрыть «избранные сверху» — поэтому закрепление
  сверху не делаем, ограничиваемся фильтром и звёздами.
